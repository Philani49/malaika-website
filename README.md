
## Project Overview

This repository contains the source code for the official website of 
**Malaika Beauty Parlor & Boutique**, owned by Ms. LMJ Mogapi. The website 
was designed and developed by **OGA Corp** as part of the Work Integrated 
Learning module (XISD6329) at The Independent Institute of Education (IIE) 
Rosebank College.

The website serves as the public-facing digital presence for Malaika, 
complementing the native Android mobile application developed in Semester 1 
(XISD5319). Both platforms share the same Firebase backend.

## Project Background

This project was initiated in Semester 1 (XISD5319) to address operational 
inefficiencies at Malaika Beauty Parlor & Boutique, including:

- Manual appointment booking via WhatsApp
- No centralised staff calendar
- No online clothing catalogue
- No web presence

The Android mobile application was built in Semester 1. In Semester 2 
(XISD6329), the scope was expanded to include this companion website, 
giving Malaika a full dual-platform digital presence.
